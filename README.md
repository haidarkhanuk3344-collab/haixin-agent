# 海辛 · Haixin Agent

一个围绕同一个人持续相处、记住背景、处理事情并主动跟进的个人 Agent。

海辛把聊天、长期和短期记忆、资料阅读、日程与提醒接在同一条对话里。它运行在自己的 Mac 上，沿用 OpenClaw 执行工具循环、DeepSeek 提供模型能力。

**当前为可试用的本机 Alpha。** 不是托管的多用户服务，也不代表每一种自然语言表达都能准确执行。公开仓库不包含作者的聊天、记忆、账号、密钥、运行数据或竞品拆解材料。

## 能做什么

- 自然聊天中检索和补读已授权资料，生成、下载和继续修改 Markdown 文档。
- 整理长期关系、经历、决定和近期处境，查看来源与版本，更正或忘记。
- 内置日程、待办和笔记；有明确时刻的安排默认提前 30 分钟提醒一次。
- 使用对话内消息和 macOS 通知；普通提醒不依赖到点调用模型。
- 将获准资料的变化关联到未完事项，准备本地成果、主动分享，再接着用户的回复办理。
- 查询 DeepSeek 官方余额，处理持久队列、有限重试、取消、未知结果和备份遗忘恢复。

例如可以直接说：

> 我最近在筹备摄影展，优先考虑离家近的场地。
>
> 明天下午四点我要交展览方案。
>
> 读取我给你的两份场地资料，整理对照，保留尚未确认的信息。

以真实保存回执和结果为准，不以模型口头答应代表完成。

## 开始使用

已验证环境：macOS、Python 3.9、Node.js 26、OpenClaw 2026.10.8、DeepSeek 官方接口。其他平台或版本尚未完整验证；macOS 钥匙串和通知适配是当前运行依赖。

1. 安装并配置自己的 [OpenClaw](https://github.com/openclaw/openclaw)，使用 DeepSeek 官方接口。不要复制他人的运行目录或账号文件。
2. 克隆本仓库：

   ```sh
   git clone https://github.com/haidarkhanuk3344-collab/haixin-agent.git
   cd haixin-agent
   ```

3. 按[本机配置指南](docs/setup.md)连接自己的 OpenClaw、工作区和钥匙串凭据。
4. 安装并构建界面：

   ```sh
   cd frontend
   npm ci
   npm run build
   cd ..
   ```

5. 启动：

   ```sh
   python3 launch_web.py
   ```

   打开 `http://127.0.0.1:18789/`。关闭网页后，后台继续处理已接受的工作；Mac 关机或休眠期间不承诺触达。重启电脑后重新运行入口。

需要 Mac 通知时，在装有 Xcode 命令行工具的本机运行 `python3 scripts/build_notifications.py`，然后在“记忆与设置”开启通知。该命令生成本机自签名的 `~/Applications/海辛通知.app`，不是已经公证的发行安装包。

## 架构与数据

React 页面 → Python 本机 API / 持久队列 → OpenClaw 工具循环 → DeepSeek。

个人记忆、事项和授权资料存于本机 SQLite 与文件。system prompt、按需检索、受控工具、成果核验、事件调度和恢复逻辑共同构成执行约束。主动事件与用户对话复用同一工具循环，不是单独的通知文案程序。[架构说明](docs/architecture.md)

本机存储不等于完全离线：调用模型会发送必要上下文，读取网页也会访问相应服务。余额是官方查询快照，本地费用只是历史参考估算；不自动充值。

**不要把当前本机 API 直接映射到公网。** 它面向单个可信本机用户，未实现多用户账号、租户隔离或公网服务防护。公开展示应使用独立示例数据，真正的多用户服务需要另行适配。[安全说明](SECURITY.md)
